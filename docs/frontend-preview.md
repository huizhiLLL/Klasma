# 正式前台验证

## 运行与入口

通过 `npm run dev` 启动前台。软件与工程资产从构建内的静态目录读取，当前收录 Mole 和四张图片。工程资产及作品目录目前为空。

| 入口 | 检查重点 |
| --- | --- |
| `/` | 收藏牌、身份区域、集合导航与共享元素路径 |
| `/tools`、`/tools/mole` | 真实图标和截图、横屏缩略图、Dock、正文预览与阅读全文、外部链接 |
| `/library` | 固定五类、真实条目计数、分类预览 |
| `/library/:category` | 当前空状态、分类运镜和返回 |
| `/library/:category/:slug` | 有内容时检查 Markdown、图片、代码复制、附件与链接。无效 slug 显示未找到 |
| `/projects` | 静态作品注册表与空状态 |

## 自动验证与边界

- Node 逻辑测试覆盖路由、静态目录、分类几何、媒体布局、作品与动画生命周期。
- `npm run verify:frontend` 在 Node 中渲染 Mole、五个分类、空状态、未找到状态和注入的工程资产详情，同时检查四张图片、字体和图标文件。
- 发布后可直接请求 `/tools/mole` 和 `/library/sfm` 核对 SPA 入口，再请求各图片检查状态码、媒体类型和文件内容。已下线的 API 路径遵循静态 SPA 回退规则。
- 浏览器视觉、焦点、滚动、下载和动效需单独验收。浏览器自动化及截图仅在用户要求时运行。
