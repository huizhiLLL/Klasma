# 正式前台验证

公开页面已使用真实 API，此文替代早期 mock 评审说明。独立设计原型仍保存在 docs/mockups，不参与正式构建。

## 运行与入口

按 README 启动 Vite 与本地 Worker；本地先构建并执行 D1 migration，配置 ADMIN_KEY 后从 `/admin/` 录入。软件与工程资产只展示已发布内容，未录入时显示空状态，不回退到样例。

| 入口 | 检查重点 |
| --- | --- |
| `/` | 收藏牌、身份区域、集合导航与共享元素路径 |
| `/tools`、`/tools/:slug` | 真实图标和截图、横竖媒体、Dock、长文溢出与阅读全文、全部链接和附件 |
| `/library` | 固定五类、真实条目计数、分类预览 |
| `/library/:category` | 真实素材场景、排序、长标题与摘要、条目数量增长 |
| `/library/:category/:slug` | Markdown、完整摘要、代码复制、真实图片、全部附件与链接 |
| `/projects` | 真实静态作品注册表；当前为空，不展示虚构作品 |
| `/admin/` | 30 天登录、类型录入、媒体、保存 / 发布 / 取消发布 |

无效 slug / 分类显示未找到；请求失败显示错误并可重新加载；请求中显示加载状态。早期 `?preview=` 参数不再覆盖真实页面状态。取消发布后新请求不再获得该资源及其上传文件。

## 自动验证与边界

- Node 逻辑测试覆盖路由、内容适配、会话过期、导航保护、分类几何、媒体布局和动画生命周期。
- `verify:frontend` 使用注入的测试 API 记录进行服务端渲染，覆盖加载、错误、空内容、真实图片路径和详情；它不向正式应用注入样例。
- `verify:api` 通过本地 Worker 的真实 HTTP 请求验证会话、CRUD、发布校验、标签、上传、附件访问和草稿隔离。
- 以上检查不代替浏览器视觉、焦点、滚动、下载和动效验收。浏览器自动化及截图仅在用户要求时运行。
