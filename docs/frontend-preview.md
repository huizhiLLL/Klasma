# 正式前台 mock 评审

## 运行

`npm install` 后运行 `npm run dev`，以终端输出的本地地址为准。公开页面完全使用本地示例，不需要启动 Worker。访问 `/admin` 时仍需 `npm run cf:dev` 与本地管理配置；后台内容不影响公开样例。

## 评审边界

- 所有作品均为虚构样例，所有媒体均为 DOM / CSS 自拟示意。Mole 使用真实官网链接，文章不是测评，也不引用作者实际观点。正式 logo、截图和个人作品等待后续替换。
- 字体为官方完整 unicode 分片，自托管、按需加载；不是原型固定字集缓存。`public/fonts/sources.json` 保存来源与 SHA-256，许可随字体保留。
- SFM 只演示人工编排的顺序，不执行代码；结构图是几何示意，不解析 NBT，也不保证对应实际有效多方块。下载文件均明确标注示例。
- 已提供响应式样式、原生 modal、Escape、焦点恢复、背景隔离、键盘和 reduced motion 降级。实际移动端重排、动效、阅读溢出、原生 dialog 与屏幕阅读器表现仍需浏览器评审。
- Blog / Weekly 未配置地址，显示为未开放文字，不生成假链接。

## 当前验证（2026-10-30）

- 类型检查、lint、14 项 Node 逻辑测试与生产构建。新增检查覆盖滚轮环形重定向、进入 / 返回方位映射、资产快照分时命名、快速中断与静态降级；快照测试模拟生命周期，不验证浏览器绘制。
- `npm run verify:frontend`：42 次组件服务端渲染（含完整应用入口和三集合外壳），检查完整样例与异常状态、History 去重 / 查询变更 / replace / 滚动保留、337 条字体清单哈希、图标与下载文件。
- 不运行浏览器自动化或截图；服务端渲染不作为视觉验收证据。
- 未推送、未部署、未进行远程数据库迁移或资源写入。

## 2026-10-30 浏览器评审反馈

- 首页释义紧邻 Klasma 右侧；去掉牌面「进入」、页底「选择一张牌」和整个预览页脚。
- 集合标题三个词使用同一连续进度同步位移 / 缩放，可从中间帧改选；软件图下只显示居中的真实画面缩略图。
- 披萨缩小居中，不放右侧说明；扇形平滑放大，缩略预览按类别方位出现。
- 场景返回采用反方向的圆弧片段，右上进入则左下返回；小屏仍维持反向关系。
- 资产详情的标题与缩略图通过原生 View Transition 在条目和 native dialog 之间双向过渡；直达详情静态显示，不支持该 API、键盘或 reduced motion 时静态切换，不影响阅读与关闭。
- 独立 `theme.html` 同步这些已确认规则；完整旧布局原型仍作早期参考，以正式 React 页与 `design.md` 为当前依据。
