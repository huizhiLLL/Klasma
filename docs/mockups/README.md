# Klasma 布局与交互原型

2026-10-29。独立于应用的五视图原型，仅用于确认布局与切换关系。原生 HTML、CSS、JavaScript，无新增依赖，不接 API，不参与正式页面实现。

## 打开

在当前目录运行 `python -m http.server 4174 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:4174`。也可直接打开 `index.html`。

顶部导航仅供评审时快速跳转，不是正式站点导航。视图支持 `#home`、`#software`、`#projects`、`#library`、`#scene`。

## 手机端完整评审

打开 `http://127.0.0.1:4174/mobile.html`。同页展示首页、软件展台、全文阅读、作品、工程资产分类、分类场景、资产详情七个可独立操作的窗口。可选择 360 × 800、375 × 812、390 × 844、430 × 932，以及 320 × 568 窄屏尺寸，也可只显示一个视图。

这些尺寸是评审样本，不对应特定设备型号或最终断点。窗口通过 iframe 使用同一份原型代码与响应式样式，不维护另一套内容。手机上也可直接打开 `index.html`，按实际视口查看。

本轮移动布局均为待评审候选：首页竖向错位牌组；集合胶囊移至标题上方；作品底部横向切换器；工程资产先点分类预览、再点缩略图进入。资产详情暂保留遮罩容器，不提前固定各类型详情布局。

## 已同步的新决策

- 首页个人身份、候选签名、站名释义和 GitHub / Blog / Weekly 入口；真实头像与其他社交链接仍待提供，Blog / Weekly 不连接假地址。
- 软件固定高度文案预览，实际溢出时才显示阅读全文；桌面遮罩阅读弹窗，移动端全屏阅读层。关闭后保留软件与媒体选择。软件 B 使用短文，其余使用长文示例；展开入口是否出现取决于当前可用高度。
- 集合页独立 Home 图标与 Prefer / Make / Keep 胶囊，选中滑块和标题第三词竖向滚轮对应同一次导航。首页无该胶囊，也无头像到 Home 的过渡。

## 评审重点

- 首页：三张浅色收藏牌，整体平衡、单牌倾斜，悬停抽起，点击展开进入集合。
- 软件：桌面左侧固定媒体及手动缩略图，右侧固定文案预览，底部 Dock 切换；移动端媒体与预览纵向排列。软件切换演示向原图标收起、从新图标展开。
- 作品：右侧竖向入口，左侧上下换场，各项目采用不同媒体占位；点击展示按钮观察状态变化。此处的三个项目仅为布局样本，不代表实际作品。
- 工程资产全局：悬停或聚焦扇区只显示预览气泡，点击后进入分类场景；缩略图与场景采用共享元素过渡。
- 工程资产场景：资产分布在不同位置，点击打开详情遮罩；关闭仍在原场景，角落返回全局。本轮先以 SFM 的左下角返回为例，其余分类的最终方位映射继续设计。

## 边界

媒体与 logo 均为几何或字母占位，非真实软件截图、蓝图或作者 logo。Mole 的文案仅作为排版示例，不构成测评。下载与官网按钮只提示占位，不连接假地址。详情弹窗只验证容器和返回，不设计内容。共享元素、标题滚轮与导航滑块使用浏览器 View Transition API，缺少支持时直接切换；reduced motion 与键盘操作不播放大幅过渡。触屏与窄屏分类采用两步进入，方向与返回位置的细节仍待评审。

CSS 中字号、间距、颜色、圆角和动效数值仅为原型候选，不代表正式设计 token。窗口收拢使用缩放与平移模拟方向，未复刻 macOS 曲面形变；场景图形是平面示意，未实现 3D 渲染或 SFM 执行追踪。正式需求与确认记录见 `../design.md`。
